# Telegram-бот: сводка чата за 24 часа

Бот собирает новые сообщения группы. Он сам отправляет сводку каждый день в 09:00 по заданному часовому поясу, а команда `/dashboard` позволяет запросить её в любой момент:

- что обсуждали: похожие сообщения объединяются в темы, в каждой показывается связное описание с опорой на реальные реплики;
- сколько сообщений и фотографий было;
- кто писал чаще всего и когда чат был активен;
- условный «IQ» каждого активного участника и среднее по участникам;
- какие слова встречались чаще всего;
- до шести последних фотографий с подписями.

Темы определяются локально по совпадающим словам. Описания строятся по литературным шаблонам из реплик участников, без ИИ, внешних сервисов и оплаты. Бот не придумывает выводы, которых не было в переписке. Пустой блок фотографий не выводится.

«IQ» — **игровой показатель особенностей текста**, а не измерение интеллекта человека. Он учитывает разнообразие слов, развёрнутость сообщений, объяснения причин и примеры, тематическую связь ответов с репликами других участников и вопросы. Повторяющиеся и слишком короткие сообщения снижают балл. Оценка появляется, когда участник написал минимум два сообщения и восемь значимых слов за сутки. Среднее считается только по таким участникам. Не используйте числа как реальные IQ или для серьёзных выводов о людях.
Служебные события Telegram (например, добавление участника) в статистику сообщений не входят.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен. Не публикуйте его и не записывайте в файлы проекта.
2. Отключите режим приватности: BotFather → `/setprivacy` → выберите бота → **Disable**. Затем добавьте бота в группу **заново**. Альтернатива — назначить его администратором группы. Это нужно, чтобы бот получал обычные сообщения, а не только команды.
3. Установите Python 3.11 или новее. В папке проекта выполните:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:BOT_TOKEN = "токен_от_BotFather"
$env:DASHBOARD_TZ = "Asia/Qyzylorda"
$env:AUTO_REPORT_TIME = "09:00"
.\.venv\Scripts\python.exe bot.py
```

В Linux/macOS используйте `python3 -m venv .venv`, затем `.venv/bin/python` вместо `py` и Windows-пути. Часовой пояс задаётся переменной `DASHBOARD_TZ` в формате IANA; по умолчанию используется UTC.

4. Напишите `/dashboard` в группе. `/help` показывает краткую справку. Ежедневный отчёт отправляется автоматически в `AUTO_REPORT_TIME` по часовому поясу `DASHBOARD_TZ`. Время задаётся в формате `HH:MM`, по умолчанию `09:00`. Бот должен оставаться запущенным постоянно; раздел хостинга **Scheduled commands** для этого не нужен.

Можно задать путь к базе: `DASHBOARD_DB=...`. По умолчанию рядом с ботом создаётся `dashboard.sqlite3`. На хостинге для этой базы нужен постоянный диск: в ней находятся сообщения за 24 часа и отметки об уже отправленных ежедневных отчётах. Если хостинг удаляет файлы при перезапуске, сводка потеряет накопленную историю, а автоматическая отправка может повториться.

## Важное ограничение Telegram

Бот **не может прочитать старую историю** до своего добавления. Первые 24 часа отчёт будет постепенно заполняться. Если режим приватности включён, отчёт будет неполным. Telegram хранит неполученные обновления не более 24 часов, поэтому процесс лучше держать постоянно запущенным.

Бот хранит текст, имена отправителей и Telegram ID фотографий в локальной SQLite-базе. Записи старше 24 часов удаляются при обработке сообщений и во время ожидания новых. Сами фотографии загружаются только для построения отчёта и в базе не хранятся. Изображение отчёта отправляется обратно в тот же групповой чат. Команда `/dashboard` в личном чате не раскрывает данные группы.

## Проверка без Telegram

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe demo.py
```

`demo.py` создаёт `demo_dashboard.png` с вымышленными данными и `demo_compact.png` без фотографий.
